# «Русский на 100» — вёрстка лендинга

Готовая статичная страница: HTML + CSS + немного JS, без сборки и без фреймворков.
Достаточно выложить папку на хостинг или встроить в CMS. Открывается и локально: `index.html`.

## Состав

```
index.html            — вся страница (одна, лендинг с якорями)
css/site.css          — стили
js/site.js            — меню на телефоне, появление блоков, подсветка пунктов меню, запись через мессенджеры, модалки
img/photo1-3.jpg      — фотографии (1800 px по длинной стороне)
img/favicon.svg       — иконка сайта
img/logo-mark.svg     — знак логотипа «Я со стрелкой» отдельно
fonts/…ttf            — шрифт заголовков TT Bluescreens Condensed Bold (см. «Шрифт»)
```

Внешние зависимости: только Google Fonts (Manrope — текст, Oswald — запасной для заголовков), подключены в `<head>`.

## Что нужно доделать

1. **Контакты для записи** (`#contact`). Формы с отправкой на сервер больше нет: посетитель выбирает цель, сайт составляет текст сообщения и открывает Telegram (текст подставляется в чат), ВКонтакте (текст копируется в буфер) или показывает ID WeChat с кнопками «Скопировать».
   Ники задаются в одном месте — атрибуты у блока `<div class="msg" data-msg …>` в `index.html`:
   `data-tg` — ник в Telegram без @, `data-vk` — короткий адрес страницы ВК (из vk.com/<адрес>), `data-wechat` — WeChat ID.
   Сейчас там заглушки `TG_USERNAME`, `VK_USERNAME`, `WECHAT_ID` — их же надо заменить в двух ссылках `href` рядом (на случай, если JS не загрузится).
2. **Превью для соцсетей.** В `<meta property="og:image">` указан относительный путь `img/photo2.jpg` — заменить на полный адрес (`https://домен/img/photo2.jpg`) и добавить `og:url`.

## Шрифт

Заголовки набраны шрифтом **TT Bluescreens Condensed Bold**. В папке лежит **пробная (trial) версия** — для публичного сайта нужна купленная веб-лицензия у TypeType. После покупки заменить файл в `fonts/` и путь в начале `css/site.css` (`@font-face`).
Если шрифт не загрузится, заголовки автоматически покажутся шрифтом Oswald — вёрстка не развалится.

## Как устроены стили

- Цвета заданы переменными на `body.v03` в начале `css/site.css`: `--p` королевский синий `#1B3A8C`, `--a` золото `#E8B23A`, `--ag` золотой перелив для кнопок, `--bg`, `--sf`, `--tx` — фоны и текст.
  Вторичный текст — `--tx2` (цвет, а не прозрачность, ради контраста), линии-разделители — `--line`.
- Адаптив: брейкпоинты 1280 px (шаги мастерской в 3 колонки), 1100 px и 760 px. Проверено на ширине 375–1440 px, горизонтальной прокрутки нет.
- Анимации уважают системную настройку «уменьшить движение» (`prefers-reduced-motion`).
- Блоки с классом `.rv` проявляются при прокрутке (добавляется класс `.in`). Анимация включается, только если работает JS (класс `js` на `<html>` ставит маленький скрипт в `<head>`); без JS весь текст просто виден. При встраивании в CMS сохраните этот скрипт и подключите `js/site.js`.

## Кэш браузера

Ссылки на `css/site.css` и `js/site.js` в HTML-файлах идут с меткой версии `?v=…`. После изменения стилей или скрипта поменяйте метку во всех трёх HTML-файлах, иначе у посетителей может остаться старая версия.
